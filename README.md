# Kevin Mancuello — Portfolio

Portfolio personal de Kevin Mancuello. Sitio estático construido en HTML, CSS y JavaScript.

**El sitio vigente está en `preview/`** (https://kiamo13.github.io/Kevin-Mancuello/preview/). El `index.html` de la raíz solo redirige ahí; `script.js`, `styles.css` y `assets/` de la raíz son la versión anterior.

## Estructura

- `index.html`: contenido y estructura del portfolio.
- `styles.css`: sistema visual y diseño responsive.
- `script.js`: interacciones del menú y del avatar.
- `assets/avatar.svg`: ilustración vectorial original del avatar.

## Avatar interactivo

El SVG se carga de forma inline para conservar sus capas. JavaScript añade una máscara radial animada que permite revelar una porción del cráneo siguiendo el cursor, con inercia y deformación orgánica. También incluye seguimiento de pupilas, parpadeo y sonrisa temporal.

## Publicar con GitHub Pages

El repositorio está preparado para GitHub Pages. Para habilitarlo:

1. Abrir **Settings → Pages**.
2. En **Build and deployment**, seleccionar **Deploy from a branch**.
3. Elegir la rama **main** y la carpeta **/(root)**.
4. Guardar.

La URL esperada será: https://kiamo13.github.io/Kevin-Mancuello/
